# frontend/pwa/
APEX → Shared Components → Progressive Web App: **Enable PWA = On**, **Installable = On**.
Put `icon-192.png` and `icon-512.png` here (upload as static application files). Install: open the app URL on the phone → browser menu → *Install app*. Users: officers, cooperatives, dryer operators. Farmers use Wasiliana SMS and USSD (`ussd/`, Louisa).
